# 盘中模拟收盘价（盘中预估）

## 使用方式

打开“最新持仓标的”页，在正式收盘信号下方点击“获取盘中报价并重算排名”。此功能不自动请求行情；每次点击时才访问免费报价源。

## 报价源顺序

系统先批量请求腾讯行情。未返回当天有效报价的标的再请求新浪；仍缺失的标的最后请求东方财富。结果表逐标的显示报价来源和报价时间。无当天有效报价的标的不参与模拟排名，并显示未取得报价。

## 价格换算与排名

免费接口返回未复权现价。系统读取该标的最近一条同时具有原始收盘价和复权收盘价的历史记录，计算：

```text
换算比例 = 最近历史复权收盘价 / 最近历史未复权收盘价
模拟复权收盘价 = 盘中未复权现价 × 换算比例
```

随后将模拟复权收盘价作为当天收盘价，加入历史 `adj_close` 序列，并调用与正式策略相同的加权对数回归动量公式重算分数和排名。正式历史数据文件不会被这次模拟修改。

只接受行情源时间戳为当前上海日期的正数报价；旧日期报价会被视为无效并触发下一个数据源。结果表除未复权报价、模拟复权价、正式收盘得分、盘中预估得分、来源、时间和熔断状态外，还展示换算比例、回归日斜率、年化趋势收益率和加权 R²。

## 得分拆解

在结果表下方选择一个标的，可查看正式收盘得分、盘中预估得分、年化趋势收益率、加权 R²、复权换算比例、回归斜率/截距，以及加权 SSE、SST，并展开逐日回归表。逐日表覆盖本次使用的整个回归窗口，列出原始收盘价/盘中报价、模型使用的复权价格、对数价格、序号、回归权重、加权对数均值、拟合对数价格、残差、加权残差平方和加权偏差平方。

计算沿用项目现有实现：

```text
x = 0, 1, ..., 窗口长度 - 1
权重 = 1 + linspace(0, 1, 窗口长度)²
对数价格 = ln(模型复权价格)
日斜率 = polyfit(x, 对数价格, 1, w=权重) 的斜率
加权 R² = 1 - 加权残差平方和 / 加权总平方和
年化趋势收益率 = exp(日斜率 × 252) - 1
动量得分 = 年化趋势收益率 × 加权 R² × 100
```

结果表中的“年化趋势收益率%”是年化趋势收益率乘以 100，因此可以直接检查：`年化趋势收益率% × 加权 R² = 盘中预估得分`。逐日表中的残差和加权残差平方可用于复核拟合误差与 R²。数据不足以构成完整窗口时，不显示逐日拆解。

## 使用边界

盘中预估不是正式日线收盘价。换算比例沿用最近可用历史复权比例；若当日存在尚未写入本地历史数据的除权因子，估算结果可能与收盘后正式复权序列略有差异。免费行情接口的字段和可用性由数据源控制，来源失败时页面会展示回退情况；页面不写入模拟价格或改变历史 CSV。
