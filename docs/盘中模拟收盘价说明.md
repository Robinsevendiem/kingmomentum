# 盘中模拟收盘价（盘中预估）

## 使用方式

打开“最新持仓标的”页，在正式收盘信号下方点击“获取盘中报价并重算排名”。每次点击会先重试 Tushare 历史行情更新并校验动量窗口，然后获取免费盘中报价。若 Tushare 仍未补齐历史窗口，系统会调用东方财富日线接口临时补齐本次计算所需的未复权/前复权收盘价。

**数据隔离说明：**东方财富补充的历史收盘价和免费行情源获取的盘中价格，仅作为当前盘中模拟的临时输入，不写入数据库或历史 CSV，也不会回写、覆盖或混入后续通过 Tushare Token 更新的数据。点击时触发的 Tushare 更新仍按项目原有流程单独更新 Tushare 历史文件。

## 报价源顺序

系统先批量请求腾讯行情。未返回当天有效报价的标的再请求新浪；仍缺失的标的最后请求东方财富。结果表逐标的显示报价来源和报价时间。无当天有效报价的标的不参与模拟排名，并显示未取得报价。

## 价格换算与排名

免费接口返回未复权现价。系统读取该标的最近一条同时具有原始收盘价和复权收盘价的历史记录，计算：

```text
换算比例 = 最近历史复权收盘价 / 最近历史未复权收盘价
模拟复权收盘价 = 盘中未复权现价 × 换算比例
```

随后将模拟复权收盘价作为报价日的预估收盘价，加入报价日前历史 `adj_close` 序列，并调用与正式策略相同的加权对数回归动量公式重算分数和排名。Tushare 交易日历会用于核对最近策略窗口的开市日；发现缺口时，先由 Tushare 更新逻辑尝试修复，再用东方财富日线补缺。东方财富和 Tushare 序列存在重叠时，以最近共同有效日期的复权价格比例对齐复权尺度；没有重叠日期时，不混合两套复权序列，而改用东方财富完整窗口计算。只有每个参与排名的标的都有完整有效窗口后才生成模拟排名；若东方财富仍缺少所需日期或有效历史不足，页面会列出标的和缺失情况并停止生成分数。

结果表的“历史数据来源”标明每个标的采用 Tushare 本地历史、Tushare 加东方财富补缺，或东方财富完整窗口；逐日拆解表也会标出每个历史观测点的来源。模拟日期这一行标为“实时报价：来源”，报价列单独显示腾讯、新浪或东方财富的实时来源。临时模拟数据只参与当前计算，不会写入数据库、CSV 或 Tushare 历史数据。

盘中模拟只用报价日前的日线作为历史窗口，并以免费行情源的实时价格替代当日收盘价。最新持仓信号页则会使用 Tushare 返回的最近开市日数据；如果最近开市日是今天，表示 Tushare 已返回当天收盘日线，页面会标明信号采用今日收盘行情。若 Tushare 尚未返回当天数据，系统会在所有标的的前一交易日窗口完整时统一回退到该日。Tushare 更新接口报错但本地文件已完整覆盖目标日和整个动量窗口时，仍可使用本地完整数据；若本地窗口不完整，则尝试东方财富在线日线补数，并显示数据来源及失败标的/日期。系统不会把旧数据误报为最新同步成功。

如果今日收盘行情已通过 Tushare 同步，页面会禁用“获取盘中报价并重算排名”按钮，避免再次请求腾讯、新浪或东方财富报价。若按钮触发的 Tushare 更新刚好取得今日收盘数据，系统也会直接计算正式收盘信号并跳过实时报价。若调整了策略参数或需要刷新正式信号，可点击上方“重新同步数据并计算最新信号”按钮。

只接受行情源时间戳为当前上海日期的正数报价；旧日期报价会被视为无效并触发下一个数据源。结果表显示“前一完整交易日收盘得分”和对应日期，与当前盘中预估得分分列；同时展示未复权报价、模拟复权价、来源、时间和熔断状态，以及换算比例、回归日斜率、年化趋势收益率和加权 R²。

## 得分拆解

在结果表下方选择一个标的，可查看前一完整交易日收盘得分及日期、盘中预估得分、年化趋势收益率、加权 R²、复权换算比例、回归斜率/截距，以及加权 SSE、SST，并展开逐日回归表。逐日表覆盖本次使用的整个回归窗口，列出原始收盘价/盘中报价、模型使用的复权价格、对数价格、序号、回归权重、加权对数均值、拟合对数价格、残差、加权残差平方和加权偏差平方。

计算沿用项目现有实现：

```text
x = 0, 1, ..., 窗口长度 - 1
权重 = 1 + linspace(0, 1, 窗口长度)²
对数价格 = ln(模型复权价格)
日斜率 = polyfit(x, 对数价格, 1, w=权重) 的斜率
加权 R² = 1 - 加权残差平方和 / 加权总平方和
年化趋势收益率 = exp(日斜率 × 252) - 1
动量得分 = 年化趋势收益率 × 加权 R² × 100
```

结果表中的“年化趋势收益率%”是年化趋势收益率乘以 100，因此可以直接检查：`年化趋势收益率% × 加权 R² = 盘中预估得分`。逐日表中的残差和加权残差平方可用于复核拟合误差与 R²。数据不足以构成完整窗口时，不显示逐日拆解。

## 使用边界

盘中预估不是正式日线收盘价。换算比例沿用最近可用历史复权比例；若当日存在尚未写入本地历史数据的除权因子，估算结果可能与收盘后正式复权序列略有差异。免费行情接口的字段和可用性由数据源控制，来源失败时页面会展示回退情况；页面不写入模拟价格或改变历史 CSV。
