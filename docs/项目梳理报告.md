# KingMomentum 项目梳理

## 项目定位

这是 `kingmomentum.streamlit.app` 对应的 ETF 动量轮动回测与分析项目。Streamlit Cloud 主入口为 `Home.py`；线上导航包括首页、Momentum Analysis、Parameter Analysis、交易时点对比和更新记录。项目 GitHub 远程为 `origin`（`Robinsevendiem/kingmomentum`），当前工作分支为 `main`。

项目功能、安装方式和部署设置以根目录 [README](../README.md) 为准；本文件用于快速查找维护资料。

## 目录导航

| 资料 | 位置 | 用途 |
| --- | --- | --- |
| Streamlit 主应用 | `Home.py` | 首页、回测、当前信号、数据更新和页面导航 |
| 多页应用 | `pages/` | 动量分析、参数分析、交易时点对比、更新记录 |
| 运行数据 | `data/` | ETF 历史行情、轮动池、自定义资产和参数分析结果 |
| 行情与复权工具 | `data_update_utils.py` | 本地数据更新及前复权价格重建 |
| 盘中免费行情 | `intraday_quotes.py` | 腾讯、新浪、东方财富报价解析及逐源回退 |
| 盘中预估口径 | `docs/盘中模拟收盘价说明.md` | 未复权报价换算、动量重算和使用边界 |
| 离线分析和研究脚本 | `scripts/` | 回测、数据下载、因子分析和参数研究 |
| 历史产物 | `archive/` | 旧版应用、研究脚本、报告和历史对照数据 |
| 项目说明 | `README.md` | 本地运行、依赖、Streamlit Cloud 部署与数据说明 |
| 运行依赖 | `requirements.txt` | Streamlit Cloud 安装的固定版本依赖 |
| 开发依赖 | `requirements-dev.txt` | 本地离线研究所需的附加依赖 |
| Python 版本 | `runtime.txt` | Streamlit Cloud Python 运行时版本 |

## 线上应用启动与依赖排查

Streamlit Cloud 应用的主文件应指向 `Home.py`。启动错误优先核对应用部署日志、`runtime.txt`、`requirements.txt` 和入口文件导入。不要把 `archive/` 中的旧页面或历史脚本当作当前线上应用入口。

本次线上错误显示 `Home.py` 导入 `tushare` 时，其内部导入 `six` 失败。为避免托管环境遗漏该传递依赖，当前 `requirements.txt` 已显式固定 `six==1.17.0`。
